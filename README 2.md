# مدارس الناصرية

دليل مدارس الناصرية ومحافظة ذي قار.

- الموقع: `index.html`
- لوحة التحكم: `admin.html` (بدون رابط ظاهر في الموقع)
- البيانات المنشورة: `site-data.js`

## تحديث البيانات
1. من `admin.html` عدّل ما تشاء ثم اضغط **نشر التعديلات** (ينزل ملف `site-data.js`).
2. في هذا المستودع: **Add file ← Upload files** وارفع `site-data.js` بنفس الاسم (يستبدل القديم) ثم **Commit**.
3. بعد دقيقة تقريباً حدّث الموقع بـ Ctrl+F5.
